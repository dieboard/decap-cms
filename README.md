# Decap CMS with Hugo Starter

This is a basic website built with Hugo and Decap CMS, intended to be deployed to GitHub Pages.

## How to run locally

1. Clone the repository.
2. Run `npm install` to install the dependencies.
3. Run `npm start` to build the site and start a local server.

## How to log in to the CMS

Once the site is deployed to GitHub Pages, you can log in to the CMS at `/admin/`. You will need to create a GitHub OAuth App and add the credentials to your repository as secrets.
